# Casa Grande · Revisión de productos

Sitio estático para revisar las relaciones de los 419 productos locales activos con los 226 productos activos de Alegra. Corte del catálogo: 2026-11-05.

Abra `index.html` directamente o sirva esta carpeta con un servidor estático. No requiere instalación ni claves API.

Las decisiones se guardan en localStorage del navegador y pueden exportarse/importarse como JSON. Al terminar, la persona revisora debe enviar el archivo exportado al encargado del sistema. No hay sincronización entre dispositivos ni cambios automáticos en el programa o Alegra.

Las coincidencias exactas son propuestas que requieren aprobación explícita. Las sugerencias por similitud no confirman porción, preparación ni impuestos. Los datos publicados contienen únicamente nombres, tipos e identificadores de productos activos; no contienen credenciales, clientes ni ventas.

`DUDOSO` registra una revisión que necesita aclaración; no aprueba una vinculación. Crear o desactivar son propuestas para una fase posterior.
